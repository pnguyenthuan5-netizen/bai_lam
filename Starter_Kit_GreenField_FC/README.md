# Bộ tài nguyên bài ôn tập GreenField FC

1. Mở `Bai_on_tap_Quan_ly_doi_bong.docx` để xem yêu cầu bài tập.
2. Giải nén thư mục `starter-kit` và làm bài trên bản sao của `GreenField_FC`.
3. Ghi kết quả vào `starter-kit/bai_lam.md`.

`GreenField_FC/.env` chỉ chứa dữ liệu giả lập. Không đưa file này lên GitHub.
