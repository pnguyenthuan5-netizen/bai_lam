## 2. Hướng dẫn nhanh

1. Chuẩn bị môi trường làm việc:
   - Cài đặt trình soạn thảo mã nguồn (VS Code).
   - Cài đặt Git trên máy tính cá nhân.
2. Clone dự án về máy bằng lệnh `git clone`.
3. Khởi chạy máy chủ phát triển cục bộ.

* Xem thêm tài liệu chi tiết tại [Trang chủ dự án](web/index.html).
* Tìm hiểu thêm cú pháp định dạng tại [Hướng dẫn Markdown của GitHub](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).
